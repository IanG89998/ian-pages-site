Personal AI Workspace

Personal AI Workspace is a private, single-user integration that lets a self-hosted assistant (built on the open-source Hermes Agent) read and organize my own Google account data. It is not offered to the public, and no one other than its developer uses it.

Google features it accesses

  • Gmail: search and read my messages
  • Google Calendar: read my events
  • Google Contacts: read my contacts
  • Google Drive, Docs and Sheets: search and read my files

Any action that changes data (sending mail, editing events or files) requires my explicit approval each time.
